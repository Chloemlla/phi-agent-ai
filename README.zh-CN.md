phi-agent 是一个真正在你电脑上干活的桌面 AI Agent：读代码、改文件、跑命令，并把发生的一切展示给你。它运行在你的设备上，会话留在本机，动手之前先征求你的同意。

不用注册，不上传数据，不做意外的事。

> **下达任务。批准动作。看着它干活。随时收回控制权。**

## 为什么选择 phi-agent？

大多数 Agent 让你在「方便」和「可控」之间二选一。phi-agent 不做这个交易。

|  | 云端 Agent | IDE 助手 | **phi-agent** |
|---|:---:|:---:|:---:|
| 数据留在你的设备上 | — | 部分 | **默认如此** |
| 离线可用 | — | 部分 | **可以**（远程模型调用除外） |
| 能读文件、改文件、跑命令 | 有时 | 以编辑为主 | **可以——安全动作自动放行，其余询问** |
| 每次运行都被保存、可回看 | 很少 | — | **默认如此** |
| 自带模型 | — | — | **可以** |
| 换台设备继续任务 | — | — | **规划中** |

## 用起来是什么感觉

**1. 告诉它你想做什么。**
*「查一下构建为什么不稳定，然后修好它。」*

**2. 批准真正重要的动作。**
读取与修改工作区自动进行——每次写入都会备份旧内容。只读命令和项目验证命令（测试、构建、Lint）也会自动放行；其余命令会先询问，审批绑定到确切的命令与参数。

**3. 看着它干活。**
消息、工具调用、审批请求和结果会在每一步完成时出现在对话里。整次运行都留在会话中，随时可以回看发生了什么。

**4. 随时收回控制权。**
任何时候都能取消。Agent 会一直工作到任务完成或你主动停止；上下文组成、速度与缓存命中在上下文面板里按需查看。如果应用中途关闭，任务会被标记为待核对，而不是被悄悄重试。

## 自带模型

phi-agent 支持 Anthropic Messages 和 OpenAI 兼容端点。在**设置 → 模型供应商**中添加一个或多个供应商：填写端点与密钥，然后从供应商返回的模型列表中勾选要使用的模型。密钥留在你的机器上，只会发往你配置的端点。同一时间只有一个供应商处于当前状态。

输入框会显示当前模型。无需进入设置即可切换模型，并为下一条消息选择思考强度。回复会按 Markdown 渲染，包括代码块与表格。

未配置供应商时，运行会给出明确错误，而不是编造输出。把供应商指向本地的 OpenAI 兼容运行时（Ollama、LM Studio、vLLM），即可完全离线使用。

## 可以自己排版回答

当纯文字不是最好的表达时，Agent 会在回复正文里直接放一小块可操作的界面——可以勾选的清单、带进度的计划、可筛选的指标、图表，或把选择发回给你的短表单。它渲染在消息流中，外观与应用其余部分一致。

回答可以自己排版：分栏、网格、面板、带说明文字的图片，以及会跟随滑块或其他控件变化的示意图。控件是真正的 HTML：滑块、选项、清单、步骤、可折叠内容和表格。探索时状态留在页面里，直到你按下发送按钮或提交表单，才会把内容发回 Agent。图表由回复中的普通表格绘制。

模型写的东西不会执行：普通回答里，可执行脚本、样式、iframe 和事件属性都会被移除，所有可见元素都按固定白名单重建。富视觉块可以使用自定义 HTML/CSS，但会在禁用脚本的沙盒中渲染，除 https 图片外没有网络访问。链接在浏览器中打开；图片只能使用对话中出现过的 https 地址。

## 可以检查的记忆

Agent 可以保存稳定的事实——偏好、项目约定、决定——并在之后的运行中回忆起来。每条事实都记录来源和来源的信任程度；未经验证的来源置信度更低，并会被标注。

打开**设置 → 记忆**，可以搜索 Agent 记住的内容、自己添加一条事实，或永久删除一条。删除事实时，它的原文与检索索引会从记忆中一起擦除。过去的对话记录属于另一份数据，不会被改写。看起来像凭据的内容会在写入记忆前脱敏，纯密钥会被直接拒绝。

记忆保存在你的机器上——没有独立的记忆服务。被召回的事实会和你配置的模型供应商共享，与对话其余内容一样。检索失败时，Agent 会继续任务，而不是被阻塞。

## 快速开始

phi-agent 处于早期体验阶段，暂时没有打包好的安装程序，需要从源码构建。

### 环境要求

- Rust 1.89+（Windows 使用 MSVC 工具链）
- [Bun](https://bun.sh) 以及 [Tauri 2 的平台依赖](https://v2.tauri.app/start/prerequisites/)
- Windows：安装 Visual Studio Build Tools 的「使用 C++ 的桌面开发」工作负载

### 运行

```bash
bun install
bun run tauri dev
```

Android 上按 Tauri 2 的 Android 依赖安装 SDK/NDK 后，运行 `bun run tauri android dev`。界面会适配手机宽度：抽屉式侧栏、触控友好的输入区与安全区留白。

首次启动会在系统文档目录下创建 `phi-workspace` 文件夹，可在应用内修改。

## 看得见的安全边界

让 Agent 改文件、跑命令是一件严肃的事，phi-agent 认真对待：

- **默认拒绝。** 未知工具与工作区外的路径一律拒绝。
- **安全动作有白名单。** 工作区写入会备份旧内容并自动放行；只读命令与项目验证命令（测试、构建、Lint、类型检查）会被识别为安全。其余命令一律询问。
- **审批绑定动作。** 你的「同意」只对确切的工具、工作区与规范化参数有效；参数一变，或者已批准的文件发生变化，审批立即失效。
- **文件工具留在工作区。** 你选择的文件夹就是读写文件的边界。
- **命令使用你的用户权限。** 命令执行不是虚拟机级的隔离。白名单刻意收得很窄；对白名单之外的命令，审批提示才是真正的安全边界。批准前请认真阅读。
- **取消是真的取消。** 可能已经产生副作用的命令会被标记为「结果未知」，而不是假装什么都没发生。
- **用量看得见。** 上下文占用、平均速度与缓存命中都从真实调用数据计算，组成按字符比例估算并明确标注。任何运行都可以随时取消。

## 常见问题

<details>
<summary><b>phi-agent 会上传我的数据吗？</b></summary>

不会。会话与 API Key 默认留在本地。网络流量只会发往你配置的模型端点。
</details>

<details>
<summary><b>可以离线使用吗？</b></summary>

应用本身可以离线运行。模型调用需要供应商；把它指向本地的 OpenAI 兼容运行时（例如 Ollama 或 LM Studio），数据就不会离开你的机器。
</details>

<details>
<summary><b>它像虚拟机一样隔离吗？</b></summary>

暂时不是。文件工具被限制在工作区目录内，但命令会以你自己的用户权限运行。安全白名单只覆盖只读与项目验证命令；对白名单之外的命令，请把审批提示和你的工作区选择当作真正的边界。
</details>

<details>
<summary><b>支持哪些模型？</b></summary>

支持 Anthropic Messages 和 OpenAI 兼容端点（Chat Completions 或 Responses），也包括暴露 OpenAI 兼容接口的本地运行时。
</details>

<details>
<summary><b>我的 API Key 存在哪里？</b></summary>

保存在你的机器上。应用保存的是引用——环境变量名（`env:NAME`），或开发期使用的字面值（存在本地数据目录）。真正的值只会发往你配置的端点。
</details>

<details>
<summary><b>任务跑到一半关掉应用会怎样？</b></summary>

运行会停止，并在下次打开应用时标记为待核对。它绝不会自动重试，因为命令可能已经改动了东西。
</details>
